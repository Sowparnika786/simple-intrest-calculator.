# Simple Interest Calculator

This project is a simple interest calculator.

## Description

The calculator computes simple interest based on the principal amount, annual rate of interest, and time period.

### Formula

Simple Interest = (Principal × Rate × Time) / 100

## Features

- Calculate simple interest
- Easy to use
- Lightweight and fast

## Usage

Enter:
- Principal Amount
- Rate of Interest
- Time Period

The calculator will display the simple interest.
